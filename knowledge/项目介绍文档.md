## 一、项目概述

### 1.1 项目简介
本项目是一个**基于微信小程序的知识题库系统**，采用「微信小程序前端 + Node.js 后端 + MySQL 数据库」三层架构开发。系统以中小学常见学科（语文、数学、英语）为载体，提供在线刷题、错题归集、错题回顾、题目管理和后台管理等功能，帮助用户通过移动端便捷进行知识巩固与复习。

### 1.2 核心特色
- 简洁清爽的 UI 风格（绿色主色调 `#2E7D32`），符合学习场景的视觉体验
- 三大常用入口（首页 / 错题 / 我的）通过底部 tabBar 快速切换
- 答题正确率实时计算、错题自动归集
- 后台双模块管理：题目管理 + 用户管理
- 全链路 UTF-8 编码，正确处理中文题目与解析

### 1.3 适用场景
- 中小学生课外知识巩固练习
- 教师在课后布置的趣味答题任务
- 个人学习/自考知识点的归纳与复习
- 可扩展为驾考、公考、行业认证等任意单选题题库

## 二、技术栈

| 层级 | 技术选型 | 说明 |
|------|---------|------|
| 前端 | 微信小程序原生框架 | WXML + WXSS + JS，不依赖任何 UI 框架，体积小、加载快 |
| 后端 | Node.js + Express 4 | 轻量级 HTTP 服务，监听 3000 端口 |
| 数据库 | MySQL（utf8mb4） | 支持 emoji 与全部中文字符 |
| 文件上传 | Multer | 处理头像等图片上传，存储到 `backend/uploads/` |
| 跨域 | CORS | 允许小程序直接访问后端接口 |
| 通信协议 | HTTP + JSON | 请求统一走 `app.request` 封装，约定 `code/message/data` 三段式响应 |

## 四、数据库设计

数据库名：`knowledge_db`，共 4 张表。

### 4.1 user（用户表）
| 字段 | 类型 | 说明 |
|------|------|------|
| user_id | INT AUTO_INCREMENT | 主键 |
| wx_name | VARCHAR(100) | 微信昵称 |
| wx_avatar | VARCHAR(500) | 头像 URL |
| phone | VARCHAR(20) | 联系电话 |
| create_time | TIMESTAMP | 创建时间 |

### 4.2 subject_question（题目总表）
合并「科目」与「题目」为一张表，省去单独科目表。
| 字段 | 类型 | 说明 |
|------|------|------|
| q_id | INT AUTO_INCREMENT | 主键 |
| subject_name | VARCHAR(50) | 科目名（语文/数学/英语） |
| title | TEXT | 题干 |
| option_A ~ option_D | VARCHAR(500) | 四个选项 |
| answer | VARCHAR(10) | 正确答案 A/B/C/D |
| analysis | TEXT | 解析 |
| UNIQUE KEY | (subject_name, title(255)) | 防止同科目下题目重复 |

### 4.3 wrong_question（错题表）
| 字段 | 类型 | 说明 |
|------|------|------|
| w_id | INT AUTO_INCREMENT | 主键 |
| user_id | INT | 关联用户 |
| q_id | INT | 关联题目 |
| add_time | TIMESTAMP | 添加时间 |
| UNIQUE KEY | (user_id, q_id) | 同用户同题不重复加入 |

### 4.4 admin（管理员表）
| 字段 | 类型 | 说明 |
|------|------|------|
| a_id | INT AUTO_INCREMENT | 主键 |
| username | VARCHAR(50) UNIQUE | 管理员账号 |
| password | VARCHAR(255) | 密码（注：SQL 中标记为 MD5 加密，实际存储明文 12345678） |
| real_name | VARCHAR(50) | 真实姓名 |
| phone | VARCHAR(20) | 电话 |
| create_time | TIMESTAMP | 创建时间 |

### 4.5 内置测试数据
- 科目：语文、数学、英语（每个科目 7 道题，共 21 道）
- 测试用户：`汉堡好热`
- 默认管理员：`admin` / `12345678`

## 五、后端接口清单（server.js）

所有接口均以 JSON 返回，统一结构 `{ code, message, data }`，`code=200` 表示成功。

### 5.1 题目接口
| 方法 | 路径 | 功能 |
|------|------|------|
| GET | `/getSubjectList` | 获取所有去重科目列表 |
| GET | `/getQuestionBySubject?subName=语文` | 按科目获取题目 |
| GET | `/getAllQuestion` | 获取全部题目（按科目、ID 排序） |
| POST | `/addQuestion` | 新增题目 |
| POST | `/updateQuestion` | 修改题目（需 q_id） |
| POST | `/delQuestion` | 删除题目（需 q_id） |

### 5.2 错题接口
| 方法 | 路径 | 功能 |
|------|------|------|
| POST | `/addWrong` | 加入错题（自动去重） |
| GET | `/getUserWrong?userId=1` | 获取用户错题（含题目详情，LEFT JOIN） |
| POST | `/delSingleWrong` | 删除单条错题 |
| POST | `/clearUserAllWrong` | 清空用户所有错题 |

### 5.3 用户接口
| 方法 | 路径 | 功能 |
|------|------|------|
| POST | `/login` | 用户登录（不存在则新增，存在则更新） |
| GET | `/getUserList` | 获取所有用户（管理员用） |
| POST | `/updateUser` | 修改用户信息 |
| POST | `/delUser` | 删除用户 |
| POST | `/uploadAvatar` | 上传头像（multipart/form-data） |

### 5.4 管理员接口
| 方法 | 路径 | 功能 |
|------|------|------|
| POST | `/checkAdminLogin` | 管理员登录校验 |

### 5.5 安全特性
- 所有数值型 ID 均做 `parseInt + isNaN` 校验，防止 SQL 注入与参数异常
- SQL 全部使用参数化查询（`?` 占位符）
- 题目、用户表均设有 UNIQUE 约束防止重复

## 六、前端页面与功能

### 6.1 全局封装（app.js）
- `globalData`：保存 `userInfo`、`baseUrl`、`totalExamCount`
- `request(url, data, method)`：统一封装 wx.request，自动处理业务码与错误 Toast
- `saveUserInfo / getUserInfo`：用户信息双写（内存 + 本地缓存 `wx.setStorageSync`）
- `checkLogin()`：登录态校验
- `logout()`：清空内存与缓存
- `onLaunch`：小程序启动时自动加载缓存用户信息

> **注意**：当前 `BASE_URL = 'http://192.168.0.107:3000'`，部署或换机调试时需修改为本机局域网 IP。

### 6.2 tabBar 三大主入口
1. **首页（index）** - `pages/index/index`
2. **错题（wrong）** - `pages/wrong/wrong`
3. **我的（mine）** - `pages/mine/mine`

### 6.3 各页面详解

#### ① 首页 index
- 顶部问候语：根据当前时间段显示「早上好 / 上午好 / 中午好 / 下午好 / 晚上好 / 夜深了」
- 每日学习小贴士：从 6 条励志语句中随机展示
- 用户信息卡：显示昵称与头像
- 科目卡片列表：每个科目匹配对应图标与描述（如「语文 - 诗词歌赋·阅读理解」）
- 点击科目卡片 → 跳转刷题页 `pages/exam/exam?subjectName=xxx`

#### ② 刷题页 exam
- 顶部进度条：当前题号 / 总题数、正确数、正确率
- 题目卡片：题干 + 四选项（A/B/C/D）
- 选项交互：
  - 答对：轻微震动反馈 `wx.vibrateShort`
  - 答错：自动调用 `/addWrong` 加入错题本
  - 选项着色：正确答案绿色、错误选择红色
- 三大按钮：上一题（已答不允许回退，防作弊）、下一题、跳过
- 完成弹窗：根据正确率显示不同鼓励语与表情（🏆/🎉/💪/🌱）
- 返回前确认弹窗：避免误退出
- 支持手动加入错题本

#### ③ 错题本 wrong
- 顶部统计：总错题数 + 各科目错题数（语文/数学/英语）+ 占比百分比
- 科目切换 Tab：全部 / 语文 / 数学 / 英语
- 错题卡片：
  - 折叠/展开切换（默认折叠，仅显示题干）
  - 展开后显示完整选项、正确答案、解析
  - 「再做一次」按钮 → 跳转对应科目刷题页
  - 「删除」按钮 → 二次确认弹窗
- 底部「清空全部错题」：红色危险操作，二次确认

#### ④ 我的 mine
- 用户信息卡：头像、昵称
- 微信登录按钮（当前为模拟登录，固定昵称「汉堡好热」）
- 头像上传：从相册/相机选择 → 上传到 `/uploadAvatar`
- 快捷入口：
  - 全部题目浏览 → `pages/questions/questions`
  - 我的错题 → 跳转错题 tab
  - 管理员入口 → `pages/admin/login`
- 清空错题本（带二次确认）
- 退出登录

#### ⑤ 全部题目 questions
- 顶部搜索框：实时按题干关键字过滤
- 科目筛选 Tab：全部 + 各科目
- 题目数量统计：总数 / 筛选后数 / 搜索结果数
- 科目图标支持 10 个学科（语文/数学/英语/物理/化学/生物/历史/地理/政治/科学）
- 题目卡片：点击展开看完整内容与解析
- 「加入错题本」按钮

#### ⑥ 管理员登录 admin/login
- 账号、密码输入框
- 调用 `/checkAdminLogin` 校验
- 登录成功跳转 `pages/admin/manage`

#### ⑦ 管理后台 admin/manage
顶部双 Tab：
- **题目管理**
  - 按科目筛选题目
  - 新增题目弹窗（题干、四选项、答案、解析）
  - 编辑题目（回填表单）
  - 删除题目
- **用户管理**
  - 用户列表
  - 编辑用户（昵称、头像、电话）
  - 删除用户

## 七、运行与部署

### 7.1 环境准备
1. 安装 Node.js（建议 16+）
2. 安装 MySQL 5.7 / 8.0
3. 安装微信开发者工具

### 7.2 数据库初始化
```bash
cd backend
node init_db.js
```
脚本会自动：
- 创建数据库 `knowledge_db`
- 创建 4 张表
- 插入 21 道测试题目、1 个测试用户、1 个默认管理员

### 7.3 启动后端服务
```bash
cd backend
npm install     # 首次运行需安装依赖
npm start       # 等价于 node server.js
```
服务运行在 `http://localhost:3000`

### 7.4 数据库连接配置
若 MySQL 密码不是 `123456`，请修改 `backend/db.js` 与 `backend/init_db.js` 中的 `password` 字段。

### 7.5 启动小程序
1. 打开微信开发者工具
2. 导入项目，目录指向 `miniprogram/`
3. 修改 `miniprogram/app.js` 中 `BASE_URL` 为本机局域网 IP（手机调试时需保证手机与电脑同网段）
4. 在「详情 → 本地设置」勾选「不校验合法域名」（开发期使用 HTTP）

### 7.6 默认账号
- 普通用户：自动以 user_id=1 登录
- 管理员：`admin` / `12345678`

## 八、项目亮点

1. **结构清晰**：前后端目录分离，数据库脚本独立，便于维护
2. **代码注释完整**：每个文件、每个函数均有中文注释，适合学习与二次开发
3. **统一请求封装**：`app.request` 屏蔽底层 wx.request 细节，业务层只关心 URL 与参数
4. **响应式数据驱动**：所有 UI 状态由 `data` 驱动，通过 `setData` 更新
5. **防作弊设计**：已答题不允许回退到上一题
6. **错题自动归集**：答错即静默加入错题本，无需用户手动操作
7. **数据完整性**：通过 UNIQUE KEY 防止同用户同题重复，参数化查询防注入
8. **可扩展性**：科目通过 `subject_name` 字段动态管理，新增学科无需改表结构

## 九、潜在改进方向（仅供参考）

| 方向 | 说明 |
|------|------|
| 真实微信登录 | 当前 `wxLogin` 使用模拟数据，可接入 `wx.login + code2session` 实现真实 openid 登录 |
| 密码加密 | `admin.password` 实际为明文存储，建议改用 bcrypt 或真正的 MD5+盐 |
| HTTPS | 生产部署需配置 HTTPS 与合法域名，小程序正式环境强制 HTTPS |
| 题型扩展 | 当前仅支持单选题，可扩展多选、判断、填空 |
| 收藏功能 | 增加用户收藏表，与错题本区分 |
| 排行榜 | 增加刷题次数与正确率统计，支持用户间排行 |
| 答题记录 | 当前只保存错题，可增加完整答题历史表用于回顾 |
